# Program the U9 font Flash

The verified device is Spansion S29AL032D70TFI04, Model 04, 4 MiB parallel NOR, operating in x8 mode. Its bottom boot sectors are eight 8 KiB sectors followed by 63 64 KiB sectors. This procedure uses the USB-Blaster in JTAG mode with the DE1 switch in RUN.

1. Stop the terminal service. Generate and fit the [read-only Flash reader](../../lab8_restored/tools/build_flash_backup.py) from a clean Quartus project. Load its SOF via JTAG. On the Orange Pi run `python3 host/flash/backup.py NEW_PRIVATE_DIRECTORY` to capture two backups. Keep and verify them privately.
2. Generate the full-device image with `python3 host/flash/make-font-pof.py assets/fonts/superface_font.bin assets/fonts/font_manifest.json NEW_PLAN --preserve CURRENT_DUMP --preserve-sha256 VERIFIED_SHA256`. It preserves every byte beyond the font image. To prepare the recovery POF from the unmodified backup, use a separate plan directory and add `--recovery-only`.
3. Run `quartus_cpf --64bit -c NEW_PLAN/candidate.cof`, then convert its data POF back to HEXOUT with `quartus_cpf --64bit -c NEW_PLAN/candidate.pof NEW_PLAN/candidate.hexout`. Validate the conversion using `python3 host/flash/compare-hexout.py NEW_PLAN/candidate.hexout NEW_PLAN/candidate.bin`.
4. Generate and build the separate [PFL maintenance project](../../lab8_restored/tools/build_pfl.py). Configure its SOF over JTAG. In Quartus Programmer, add its PFL child as `CFI_32MB`, assign the verified data POF to that child, then save the explicit chain file. For verify, the CDF must select `OpMask(0)` on the EP2C20F484 and `Child_OpMask(2 0 2)` on the Flash. First verify the current recovery image and check that Programmer identifies Model 04 with an 8-bit data bus.
5. For Program + Verify, use `Child_OpMask(2 0 3)`. In the CDF, `FullPath` points to the PFL maintenance SOF and `PFLPath` to the data POF. Run `quartus_pgm --64bit -c CABLE PLAN.cdf`. The tested tool erases the full U9 array. The full-device candidate preserves the prior contents outside the font region. Require a successful Flash verify in the log.
6. Load the read-only SOF and run `python3 host/flash/backup.py NEW_CAPTURE_DIRECTORY --once`. Compare `flash-read1.bin` byte-for-byte against `candidate.bin`. After a match, load the terminal SOF and confirm Chinese negotiation, which requires the Flash header, SRAM readback CRC, and matching host font identity.

An independent UART capture is required for the byte comparison. A standalone Verify command against a bare POF previously returned a successful no-op. The U9 flow does not configure the separate EPCS4 serial device used for autonomous FPGA startup.
